# Cinemata 项目章程

## 使命

Cinemata 为剧集、短片、有声书、教育内容和互动叙事提供一条可复现、可审阅、供应商中立的开源媒体生产管线。

## 要解决的问题

生成式内容工具往往把剧本、素材、模型参数和最终成片混在一次性脚本里，导致结果不可复现、资产授权不清晰、局部修改成本高，也难以在团队和 CI 中协作。Cinemata 将这些内容拆成公开的数据契约、可恢复的生产任务和可追踪的资产记录。

## 目标

1. 用开放 manifest 描述剧本、场景、镜头、对白和资产。
2. 让同一份内容可输出分镜、配音、字幕、视频和社交媒体切片。
3. 记录模型、参数、来源、许可证和人工审核状态。
4. 让媒体 provider 可以替换，而不改变创作数据。
5. 建立适合开源协作的测试、插件、示例和发布流程。

## 非目标

- 不承诺全自动生成可直接发布的影视作品。
- 不内置未授权的演员肖像、声音或受版权保护的影视 IP。
- 不绑定某一个模型供应商或云平台。
- 不以绕过平台规则、版权审核或内容安全机制为目标。

## 社区原则

- 默认使用公共领域或明确授权的素材。
- 每个生成资产都应携带 provenance 和许可证信息。
- 自动化生成草稿，最终发布由人审核。
- 变更优先通过测试、示例和公开讨论验证。
- 对安全、隐私、版权和滥用风险提供公开处理流程。

## 路线

### 0.1 核心格式

完成 episode manifest、时间轴、分镜、SRT 和 provenance 生成。

### 0.2 媒体适配器

增加图片、TTS、音乐和视频 provider 接口，并提供本地 mock provider。

### 0.3 可恢复生产

增加任务 DAG、缓存、断点续跑、人工审核节点和 GitHub Actions。

### 0.4 多格式发布

输出正片、预告片、字幕包、海报、音频剧和短视频切片。
